# 智小徽 · 教师端小程序原型

厦门第一实验小学校长使用的校园管理小程序 1:1 复刻原型项目。

边界约定：禁止拓展/发挥，样式、字段、结构、icon 等全部照抄；遇到截图未覆盖、拿不准的地方，向用户确认而不是自行发明。

## 目录说明
- `legacy/miniprogram-clone.html` — 项目最初阶段：完全基于用户提供截图手工搭建的单文件 1:1 复刻原型（历史参考，已弃用）。
- `index.html` / `check.js` / `assets/` — 当前主源文件。设计基准切换为用户上传压缩包内"智小徽 · 教师端小程序"的实际前端实现，后续所有修改均在此基础上进行。
- `v3_dist/智小徽-artifact.html` — 用于发布到 Claude Artifact 平台的产物文件（已将 assets 内联为 base64、并按 Artifact 平台要求去除了自带的 `<!DOCTYPE>/<html>/<head>/<body>` 包裹标签）。这是与线上发布内容完全一致的版本。
