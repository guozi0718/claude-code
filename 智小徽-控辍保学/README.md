## 目录结构

```
智小徽-控辍保学/
├─ README.md                 本文件：总入口
├─ CHANGELOG.md              各期版本记录
└─ 第一期-关爱学生/
   ├─ README.md              本期说明
   ├─ 01-定稿-第三版/        最终交付：原型 + 需求文档 + 发布说明
   ├─ 02-历史版本/           第一版、第二版方案及第三版过程原型（只读，不再修改）
   └─ 03-过程记录/           过程稿 PRD、核对与发布记录、旧入口、仓库备份
```

仓库根目录的 `care3/` 是第一期定稿原型的英文短链接入口，指向 `01-定稿-第三版/原型/`。

## 版本管理约定

| 事项 | 约定 |
|---|---|
| 期次目录 | 新一期新建 `第N期-功能名/`，内部同样分 01 定稿 / 02 历史版本 / 03 过程记录 |
| 迭代中文件命名 | 原型 `功能-端-V主.次-日期.html`；定稿 PRD 不带版本号，过程稿带版本号放 03 |
| 定稿 | 定稿文件放 `01-定稿-*`，只在此处修改；历史与过程文件不再改动 |
| 版本标签 | 每期定稿打 Git 标签 `phaseN-vX.Y`，在 GitHub 的 Tags 中可查看、下载当时全部文件 |
| 版本记录 | 每次定稿或定稿后的修订都写入 `CHANGELOG.md` |
| 推送 | 双击仓库根目录“推送到GitHub.bat”手动推送（会同时推送标签）；在 GitHub 网页上改过文件后，先推送一次同步，再继续本地修改 |
