## 1. 需求背景

本方案复制第一版学校端完整框架，保留侧边栏及其他菜单，在“关爱管理”菜单内移除第一版关爱个案页面并替换为第三版独立关爱记录。把关爱改为逐次记录：每完成一次关爱，就保存一条独立记录。老师每次重新选择学生并填写关爱背景和实际措施；同一学生可以有多条独立记录，每条只有一份关爱内容，不在记录中追加下一次内容。学校和监管查看这些记录，监管按组织统计参与关爱的学生人数及关爱次数。第一期其他方案不覆盖、不迁移、不删除。

## 3. 文档说明

### 3.1 名词解释

| 项目 | 当前版本规则 |
|---|---|
| 关爱记录 | 一次提交形成的一条完整记录，绑定一名学生。包含学生信息、八项关爱业务字段和系统信息，不再设置上层关爱个案。 |
| 关爱类型 | 学生所处情况或问题分类，12项多选。分类不是诊断结论，也不自动判定资助或医疗资格。 |
| 关爱方式 | 这一次实际采取的措施，15项单选。多人执行仍是一次，不按执行人数增加次数。 |
| 执行人员与创建人 | 执行人员是实际参与老师，可多人；创建人是第一次提交成功的账号姓名，由系统填写，两者不能相互替代。 |
| 关爱时间与创建时间 | 关爱时间是实际发生日期，可补录；创建时间是首次创建的服务端时间，保存到秒、以北京时间显示到分钟；修改时间单独留审计。 |
| 关爱次数 | 当前查询范围内未删除的独立记录数量。只在监管组织汇总显示，不在学生底层记录列表增加次数列。 |
| 关爱学生数 | 当前查询范围内至少有一条有效记录的学生ID去重数，不能用姓名去重，也不能把各分类人数简单相加。 |

### 3.2 编写要求

本文为本端完整独立说明，不用其他PRD补全字段。所有校验和提示写在所属字段、页面或动作内；没有独立校验汇总章。最新模板完整读取自GitHub main，模板文件blob为 8fecf490895c595ca9219058a4b4ec8d7ca80c7b，模板来源提交 36ac07c8e721808726e286311c76bca31201085b。用词按业务操作说明，不把模板示例当新增业务要求。

当前原型是会话模拟：记录、图片和审计只存在本页内存，刷新恢复示例，不跨标签页或跨端同步。真实系统须在服务端做范围与权限校验、版本校验、提交去重、记录保存和审计落库，不能凭前端隐藏按钮保证权限。接口地址、错误码和事务方案【待确认】。

## 6. 功能详细说明

### 6.1 本校关爱记录列表

[本页原型](https://guozi0718.github.io/codex/关爱学生/关爱三端原型/第三版-学校端关爱管理-V1.0-20261015.html#care-v3)

#### 6.1.1 页面说明

| 项目 | 当前版本规则 |
|---|---|
| 菜单入口 | 侧边栏菜单名称统一为“关爱管理”。进入后只显示第三版关爱记录列表和详情，不保留第一版关爱个案、关联信息、关爱次数或多次关爱内容页面。关闭详情后返回“关爱管理”原列表，并保留筛选条件、页码和横向滑动位置。 |
| 使用范围 | 登录学校后进入“关爱管理”，仅查看本校授权记录。 |
| 列表对象 | 每行是一次关爱记录，不是一名学生或一个个案；同生可多行。删除关联信息列与关爱次数列。“最近关爱日期”改为“关爱时间”，因为当前行本身只有一次。 |
| 只读边界 | 本端只读，不提供新增、编辑或删除，也不提供处理/重新处理按钮。操作列唯一按钮为“详情”。老师端新增、改删后，真实服务端重新查询返回最新记录；静态演示各端不互相同步。 |
| 默认排序 | 按后端记录的首次创建日期时间倒序，后端保存到秒，同秒再按记录ID倒序稳定排列；列表显示到分钟。不是按关爱时间或最后修改时间排序。编辑任何业务字段都不重置首次创建时间，也不改变其排序依据。不显示“第几次关爱”，不将同一学生的记录合成一个个案。 |
| 分页 | 默认第1页，每页10条，显示共N条、当前页/总页、上一页/下一页；边界按钮禁用。查询/重置回第1页；末页记录删除后刷新自动回到仍存在的最后页；0条显示0总数和1/1不可翻页。 |
| 样式 | 白底卡片、浅蓝表头、绿色主操作，沿用已确认学校台账风格。列表内部左右滚动，隐藏滚动条；操作列固定右侧，同表格同一行，前面字段不能在操作列上透出。可触控/触摸板横向滑动或聚焦容器后左右方向键。 |
| 无数据、部分与失败 | 查询成功无记录显示“暂无符合条件的关爱记录”，总条数为0；部分字段缺失显示“--”，不能把读取失败当成没有记录。正式接口若仅返回部分页，保留已加载数据并按接口总数翻页，不用已加载条数假装总数；接口失败保留上一次成功列表和查询条件，允许重新查询，具体错误码、超时、重试文案【待确认】。原型一次加载会话示例数据，不模拟真实接口。 |

#### 6.1.2 查询条件（顺序固定）

| 条件 | 控件 | 必填 | 默认值 | 数据来源与枚举 | 规则、提示与异常 |
|---|---|---|---|---|---|
| 学年 | 单选 | 否 | 全部学年 | 记录实际关爱日期对应学年；每年9月1日起到次年8月31日 | 2026-09-01归2026-2027学年，2026-08-31归2025-2026学年。原型选项来自当前学校记录；正式学年字典沿系统。与创建日期是两个不同条件，可交叉筛选。学年默认值是否需从“全部”改为“本学年”未要求，本方案保持全部。 |
| 年级 | 单选 | 否 | 全部年级 | 当前学校记录学生年级快照 | 显示年级与届别。沿用已确认学校列表的独立条件，不因改学年强行清空其他筛选。筛选联动未新增，不把老师录入级联套到只读列表。 |
| 班级 | 单选 | 否 | 全部班级 | 当前学校记录的班级值 | 与年级同时AND匹配；例如全部年级+1班表示所有年级1班。来源数据使用班级ID的正式映射【待确认】，原型按班级显示值筛选。 |
| 学生姓名 | 输入＋模糊候选回显 | 否 | 空，占位“请输入学生姓名” | 当前学校授权学生 | 输入后按姓名包含模糊匹配并回显候选，去两端空白；点候选回填，同名返回多条并列年级班级区分。查询不能扩大当前学校或监管授权范围。原型没有额外字数上限，正式输入边界与防抖【待确认】。 |
| 关爱来源 | 单选筛选 | 否 | 全部 | 全部＋辍学预警、心理测评、班主任发现、任课教师反映、学生主动反映、家长反映、困难学生、欺凌事件、其他 | 本条来源是多选，筛选选中任一来源即匹配包含该项的记录，不按来源拆成多条。不是关爱类型筛选。 |
| 创建日期 | 起止日期文本框 | 否 | 开始、结束均为北京时间今天；监管下钻继承上级日期 | 本条首次创建日期，不是实际关爱日期或修改日期 | 精确显示YYYY-MM-DD，支持直接输入和日期选择，选择范围暂不限制；含起止，单边也允许。格式不合法提示“请输入正确的日期，格式为YYYY-MM-DD”；开始晚于结束时提示“开始日期不能晚于结束日期，请检查日期范围”，均保留旧列表和输入，不偷偷交换日期。 |

全部条件同时满足；输入和选择先暂存，点查询才刷新。点重置时除创建日期恢复今天外，其他条件恢复不限，并立即查询。没有关爱类型、个案状态或日期方式筛选。

#### 6.1.3 列表字段与操作

| 字段 / 区域 | 数据来源 | 显示格式 | 规则、交互、提示与异常 |
|---|---|---|---|
| 学生姓名 | 当前记录学生快照 | 完整姓名；缺失-- | 同名不合并，详情绑定记录ID。 |
| 年级 | 当前记录学生快照 | 年级（届别） | 保持独立列，不拆出额外学年列。 |
| 班级 | 当前记录学生快照 | 班级名 | 不因同名班级把不同年级合成一个学生。 |
| 创建日期 | 首次系统提交时间 | YYYY-MM-DD HH:mm，如2026-09-25 11:25 | 服务端保存到秒，列表显示到分钟；本列是默认倒序依据。编辑任何业务字段都不改变首次创建时间。详情不单独重复展示“创建日期”，只在内容卡末尾显示系统创建时间。 |
| 关爱来源 | 本条来源多选 | 居中，最多10个显示字符，超出前10字加... | 悬停原生title展示全文；鼠标移走关闭。完整选项：辍学预警、心理测评、班主任发现、任课教师反映、学生主动反映、家长反映、困难学生、欺凌事件、其他。详情可读全项。 |
| 关爱类型 | 本条类型多选 | 居中，同样超过10字省略、悬停全文 | 底层保留该列，只有上级组织汇总移除类型列。完整枚举见本文件详情字段，不向其他端文档索取。 |
| 关爱原因 | 本次原因 | 单行省略，悬停全文 | 缺失--，不把前一条学生记录的原因带入。 |
| 关爱时间 | 本条实际发生日期 | YYYY-MM-DD | 替代旧“最近关爱日期”表达；可跨学年补录，允许早于创建日期。 |
| 关爱结果 | 本次结果 | 单行省略，悬停全文 | 只来自当前记录，不是同学生所有记录中最新一条的摘要。 |
| 操作 | 当前记录ID | 固定右列，居中“详情” | 唯一按钮，所有行垂直对齐。学校和监管均无删除记录、删除个案或处理按钮。 |
| 合计说明 | 当前查询结果 | 共N条关爱记录；每页10条 | 不在每行显示关爱次数或关联信息；空时0而不是--；接口失败不算0。 |

| 按钮 / 动作 | 出现条件 | 操作结果 | 校验、提示与失败处理 |
|---|---|---|---|
| 查询 | 筛选区域 | 按上述条件重新查询并回第1页 | 失败保留条件和上次列表，具体网络错误文案【待确认】；输入无效日期在筛选区就地显示。 |
| 重置 | 筛选区域 | 全部条件回不限，留在当前学校并回第1页 | 不清空业务记录，不修改组织权限。 |
| 详情 | 每行操作列 | 显示当前单条内容弹窗 | 记录已变化或无权访问不能展示缓存的其他记录；原型提示“记录已变化，请刷新后重试”。 |
| 上一页/下一页 | 有记录列表底部 | 仅改变页码，保留筛选 | 第一页禁用上一页，末页禁用下一页；正式分页读取失败保留旧页，准确错误提示【待确认】。 |
| 横向滑动 | 字段区超出可用宽度 | 字段内部滑动，操作列右侧固定 | 隐藏视觉滚动条但不取消滚动能力；列头和数据同一表格，不复制两张表造成行高错位。 |
