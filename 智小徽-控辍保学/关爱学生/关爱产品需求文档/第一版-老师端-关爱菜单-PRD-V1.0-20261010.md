## 3. 文档说明

### 3.1 名词解释

| 名词 | 说明 |
|---|---|
| 关爱个案 | 围绕一名学生和一组关爱背景建立的记录。一个个案可持续增加多次关爱内容。 |
| 关爱内容 | 一次实际关爱形成的一条记录。多人共同执行仍保存为一条，不按人数拆分。 |
| 关爱类型 | 学生遇到的问题或需要关注的情况，共12项，可多选。它不是处理措施。 |
| 关爱方式 | 本次实际采取的措施，共15项，只能单选。 |
| 执行人员 | 实际参与本次关爱的老师，可多人；不等于提交表单的账号。 |
| 填写人 | 提交这条关爱内容的登录账号姓名，由系统记录，用户不填写。 |
| 填写时间 | 该条内容第一次提交成功的服务端时间。后端保存到秒，页面按北京时间显示到分钟；编辑后不重置。 |
| 关爱时间 | 实际开展关爱的日期，用于排序和“第几次关爱”的编号。 |
| 历史快照 | 保存或修改时留存的一份副本，用于审计；普通用户不能从页面恢复已删除内容。 |
| 继续跟进 | 本次记录中“需要/不需要”的意愿，不代表个案关闭，也不阻止有权限老师继续新增关爱。 |

#### 6.1.1 页面说明

| 项目 | 当前版本规则 |
|---|---|
| 本版本类型 | 新增页面 |
| 本版本内容 | 新增独立关爱入口、搜索、个案卡、详情入口、新建按钮和删除空个案操作。 |
| 使用角色 | 老师。查看需要已有查看权限；新建/继续关爱需要功能开关开启且学生在本人数据范围内；编辑/删除内容只限本人。无权限演示账号可看置灰入口，但直接访问和提交也会被服务端拒绝。 |

#### 6.1.2 查询条件

| 条件 | 控件 | 必填 | 默认值 | 数据来源与枚举 | 规则、提示与异常 |
|---|---|---|---|---|---|
| 学生姓名 | 搜索输入框 | 否 | 空；占位“搜索学生姓名” | 当前授权学生姓名。 | 按姓名包含匹配，不区分大小写；与数据范围同时满足。当前原型输入即筛选；正式搜索最大字数、等待时间和失败文案【待确认】。清空后恢复全部授权个案并回到列表顶部。无结果显示“暂无符合条件的关爱个案”。 |

#### 6.1.3 个案卡片和列表

| 字段 / 区域 | 数据来源 | 显示格式 | 规则、交互、提示与异常 |
|---|---|---|---|
| 数据区域 | 授权范围内有效个案 | 手机纵向卡片；页面上下滚动。 | 按个案创建时间倒序；同秒按个案ID稳定。搜索后回顶部。首次失败保留原页面并提供重试，【待确认：准确失败文案】。 |
| 学生信息 | 个案绑定学生快照 | 姓名、年级（届别）、班级；缺失`--`。 | 点击卡片或“个案详情”进入详情；学生转班/毕业后历史快照如何与最新主数据并列【待确认】。 |
| 创建日期 | 个案系统创建日期 | YYYY-MM-DD；缺失`--`。 | 实际关爱时间补录或编辑不改变。 |
| 关爱来源 | 保存来源快照 | 多项以顿号分隔，卡片单行省略。 | 详情显示全文；缺失`--`。 |
| 关联信息 | 关联快照 | 关联N条信息；无值`--`。 | 点击打开只读关联弹窗；不把线索条数算作关爱次数。 |
| 关爱类型 | 保存分类快照 | 多项以顿号分隔，卡片单行省略。 | 详情显示全文；缺失`--`。 |
| 关爱原因 | 保存背景 | 卡片最多显示摘要，详情全文；缺失`--`。 | 不使用最新关爱结果替换。 |
| 关爱次数 | 本案有效内容数 | N次；空案0次。 | 新增成功+1，编辑不变，删除-1；审计快照不计数。未知或请求失败不能显示0。 |
| 最近关爱日期 | 排序后的最新有效内容 | YYYY-MM-DD；空案`--`。 | 与最近关爱结果必须来自同一条内容。 |
| 最近关爱结果 | 排序后的最新有效内容 | 卡片摘要；空案`--`。 | 点击详情查看全文；编辑关爱时间后可能变化。 |
| 个案详情 | 当前个案 | 按钮。 | 进入详情；对象已删除提示“个案已变化，请重新进入”并刷新列表。 |
| 删除个案 | 当前个案与权限 | 有权限老师可见；学校/监管端不显示。 | 只能删除内容数为0的个案；非空点按提示“请先删除全部关爱内容，再删除个案”。 |
| 新增关爱个案 | 功能权限和学生范围 | 底部主按钮。 | 有权限进入新增页；无权限置灰，直接访问或提交提示“暂无权限”。 |
| 无数据 | 成功查询0条 | “暂无符合条件的关爱个案”。 | 搜索仍可清空；有权限可新建，无权限新建置灰。 |
| 部分数据 | 已返回部分卡片或部分字段缺失 | 已知值正常显示，缺失字段`--`；未知总数不显示0。 | 保留已加载卡片；继续加载失败时可重试，【待确认：分页方式和文案】。 |
| 全部数据 | 当前范围已全部加载 | 完整卡片和次数。 | 到底提示【待确认：是否需要】；搜索、新增、编辑、删除后重新计算。 |
