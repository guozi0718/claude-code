## 3. 文档说明

### 3.1 名词解释

| 名词 | 说明 |
|---|---|
| 关爱个案 | 围绕一名学生和一组关爱背景建立的记录。一个个案可持续增加多次关爱内容。 |
| 关爱内容 | 一次实际关爱形成的一条记录。多人共同执行仍保存为一条，不按人数拆分。 |
| 关爱类型 | 学生遇到的问题或需要关注的情况，共12项，可多选。它不是处理措施。 |
| 关爱方式 | 本次实际采取的措施，共15项，只能单选。 |
| 执行人员 | 实际参与本次关爱的老师，可多人；不等于提交表单的账号。 |
| 填写人 | 提交这条关爱内容的登录账号姓名，由系统记录，用户不填写。 |
| 填写时间 | 该条内容第一次提交成功的服务端时间。后端保存到秒，页面按北京时间显示到分钟；编辑后不重置。 |
| 关爱时间 | 实际开展关爱的日期，用于排序和“第几次关爱”的编号。 |
| 历史快照 | 保存或修改时留存的一份副本，用于审计；普通用户不能从页面恢复已删除内容。 |
| 继续跟进 | 本次记录中“需要/不需要”的意愿，不代表个案关闭，也不阻止有权限老师继续新增关爱。 |

## 6. 功能详细说明

### 6.1 分级汇总和组织下钻

[本页原型](https://guozi0718.github.io/codex/%E5%85%B3%E7%88%B1%E5%AD%A6%E7%94%9F/%E5%85%B3%E7%88%B1%E4%B8%89%E7%AB%AF%E5%8E%9F%E5%9E%8B/%E9%83%A8%E7%BA%A7%E7%9B%91%E7%AE%A1%E7%AB%AF%E5%85%B3%E7%88%B1%E7%9B%91%E7%AE%A1-V1.5-20260929.html?v=261013#care-v1)

#### 6.1.1 页面说明

| 项目 | 当前版本规则 |
|---|---|
| 本版本类型 | 新增页面 |
| 本版本内容 | 按监管层级查看关爱个案汇总，并按组织名称逐层下钻。 |
| 使用角色 | 部级、省级、地市级、区县级监管查看角色，只读。 |
| 页面入口 | 监管端一级菜单“关爱”。 |
| 返回 | 返回上一级组织；顶层返回菜单。返回时保留上一级筛选和滚动位置。 |
| 默认状态 | 从当前账号管理层级开始，默认显示直属下一级组织。 |
| 数据范围 | 只能查看当前监管账号授权行政区和下属学校。 |
| 数据更新 | 进入、筛选、点击组织、返回和刷新时读取当前层级；任何越权组织请求均拒绝并提示“暂无权限”。 |

#### 6.1.2 下钻字段和交互

| 字段 / 区域 | 数据来源 | 显示格式 | 规则、交互、提示与异常 |
|---|---|---|---|
| 当前层级标题 | 当前账号和下钻路径 | 显示当前行政区或学校名称。 | 名称完整显示；缺失时不进入下一层并标记数据异常。 |
| 组织名称 | 直属下一级组织 | 省份/地市/区县/学校名称，蓝色可点击。 | 点击名称进入下一层，不用下拉框代替。完整路径：部级：省份→地市→区县→学校→学校底层；省级：地市→区县→学校→学校底层；地市级：区县→学校→学校底层；区县级：学校→学校底层。 |
| 返回 | 当前下钻路径 | “返回”。 | 回到上一层，不跳级；保留上一层筛选、页码和滚动位置。 |
| 汇总范围 | 当前筛选完整结果 | 整数，最小0；未知显示`--`。 | 按有效关爱个案/学生及12项分类统计；一个个案多选多个类型时可同时计入多个分类，分类合计可大于个案数。 |
| 无数据 | 当前层级成功返回0个组织 | 保留标题和返回；组织表为空。 | 不显示假组织或0冒充未知；可返回/刷新。空态准确文案待确认。 |
| 部分数据 | 部分组织或汇总未返回 | 已知组织照常显示，未知指标`--`。 | 不能用已加载组织推算全部；局部失败提供重试。 |
| 全部数据 | 当前层级组织和汇总完整 | 显示全部组织、指标和分页。 | 点击任一组织继续下钻；返回后保持状态。 |
| 加载失败 | 请求失败 | 保留上一版已加载数据。 | 不清空为0；提示和重试文案【待确认：接口规范】。 |

#### 6.1.3 看板与统计

| 指标 | 数据来源 | 计算规则与范围 | 无数据 / 部分数据 / 全部数据 | 联动、提示与异常 |
|---|---|---|---|---|
| 关爱学生数 | 当前筛选有效个案按学生ID去重 | 非负整数；同一学生多个个案只算1人。 | 无数据0；部分数据用服务端完整汇总，未知`--`；全量示例3个学生显示3。 | 筛选和源数据变化后重算；请求失败保留原值并标记失败。 |
| 关爱个案数 | 当前筛选有效个案 | 非负整数；空个案也算1个；已删除个案不算。 | 无数据0；部分数据未知`--`；全量示例4个案显示4。 | 新增/删除个案后重算；删除内容不删除第一版空个案，因此个案数不减。 |
| 12项关爱类型数 | 有效个案保存的关爱类型 | 每项分别统计命中个案数；多选可重复进入不同指标。 | 每项无数据0；部分未知`--`；全量按项显示。 | 背景变更后重算；有内容后背景不可编辑。 |
