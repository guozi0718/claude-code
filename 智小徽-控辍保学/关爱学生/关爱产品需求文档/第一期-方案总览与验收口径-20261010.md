## 两版共同口径

1. 背景字段来源→关联信息→类型→原因；保存后基础卡此前有创建日期。按用户本次提供字典统一12项学生关爱分类（关爱类型、多选）和15项措施分类（关爱方式、单选）；六份独立PRD均逐项完整列出，六端使用同一共享字典。只替换关爱分类，原预警类型不变。
2. 录入／编辑仅6个业务字段：关爱时间→执行人员→方式→结果→证明材料→继续跟进。表单无填写人／时间；保存卡最后完整显示账号姓名及系统创建时间。执行人默认班主任，不代表只能班主任填写。
3. 排序依据实际关爱日期倒序，同日按不可变创建时间到秒倒序，同秒ID稳定。最早第1次、最新第N次；编辑日期重排编号但不重置填写时间，修改时间独立审计。最新摘要用同一排序。
4. 无关爱个案状态、状态筛选、完结阻断、下次跟进日期；继续跟进需要／不需要仅描述单条记录。有权限教师可持续新增，原预警处理状态及劝返不变。
5. 本人卡右侧...→底部编辑／删除／取消，非本人不能操作；编辑全部业务字段，保存及删除确认重验权限和版本。教师演示账号可切换有权限／无关爱权限，直接入口也校验。
6. 内容删除精确确认：“确认删除该关爱内容吗？删除后不可恢复！”审计保存操作账号、操作日期时间、前后快照；普通业务不提供恢复。填写时间显示北京时间YYYY-MM-DD HH:mm、服务端存秒。
7. 学校和监管关爱只读。两菜单底层表格右操作列固定，前字段内部横向无条滚动；同表同排，不遮挡、不克隆造成错行。学校内容卡不重复右侧日期，正文日期及末尾系统字段保留。
8. 来源／类型列居中，超10字前10字加...，悬停全文；关联按条数、弹窗分组全文。教师选择器取消／确定底部并列、约五行内部滚动，页面及弹窗不溢出手机。

## 两版差异

| 项目     | 第一版独立关爱菜单                     | 第二版控辍保学                                         |
| -------- | -------------------------------------- | ------------------------------------------------------ |
| 建立     | 可建空案或同时填写多次内容             | 首条成功提交才建案                                     |
| 归属     | 同生可有不同问题多案                   | 每个入口预警单独一个案，参考其他预警不合并／迁移／计次 |
| 清空内容 | 空案保留，次数0次                      | 自动移除当前预警个案卡，次数--                         |
| 删除整案 | 授权教师校验空案后再确认               | 随最后内容删除自动处理，不另设整案删除                 |
| 再次关爱 | 保留案内新增                           | 恢复关爱按钮→确认信息→下一步→内容                      |
| 背景     | 无内容且创建人／学年／权限满足才可编辑 | 首次确认后锁定；删空后新一轮重新确认                   |
| 学校操作 | 仅个案详情，无整案删除                 | 原详情及处理／重新处理保留，关爱只读                   |
| 监管操作 | 下钻底层仅个案详情                     | 下钻底层仅详情，无处理／重新处理                       |

第一版删除整案确认：“确认删除该关爱个案？删除后不可恢复！”确认时再次核验权限、有效内容0、个案版本。第二版页标题“确认关爱信息”，段标题“学生信息／关爱信息”，来源锁定控辍保学。关联提示：“当前预警自动关联。其他预警可作为历史参考；每个预警记录的关爱内容都单独保存”。

第二版双Tab劝返信息／关爱情况保留，唯一关爱背景卡在内容前，随页面滚动。有案才有卡、删空卡消失。名单四维筛选学年／年级／班级／姓名及原处理、类型、预警时间保留。关爱次数N次／--；学校取消查看关爱；监管原预警汇总字段保持预警记录数／待处理数／已处理数，不能改成关爱统计。

监管名称逐层点击：部级省份→地市→区县→学校→明细；省／市／区县从授权层起，不以树展开替代。关爱菜单汇总保留学生数／个案数，分类统计按本次12项学生关爱类型替换，不能混用预警统计；控辍预警原字段、筛选和组织分支不替换。

## 六份独立正式PRD

每份均包含本端本方案完整字段、逻辑、权限、交互、校验、提示、排序、删除分支及后端要求，不通过互相引用省略内容。旧四份文件仅历史名称说明，不再含冲突正文。

提示和校验随对应字段、页面或操作就地编写，不单列汇总章节。六份文档原集中章节的108条条件与精确文案全部迁移，既有细节保留；新增、编辑、删除的成功／失败／取消分别放回所属流程。学校及监管的教师源动作规则标明只读边界，不能误读为本端写入口。
