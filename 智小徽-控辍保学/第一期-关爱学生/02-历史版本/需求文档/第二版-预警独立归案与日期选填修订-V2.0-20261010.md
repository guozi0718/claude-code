# 第二版预警独立归案与日期选填修订

日期：2026-10-10。基线：原第二版，不采用已放弃的 V2.1 融合验证稿。本文记录此前归案与日期调整；当前第一期完整口径及发布范围以[第一期方案总览与验收口径](第一期-方案总览与验收口径-20261010.md)及对应正式 PRD 为准，不表示新增迭代或建设期次。

## 修改内容

1. 当前预警自动关联、不可取消；“关联控辍保学”弹窗提示精确改为：

   > 当前预警自动关联。其他预警可作为历史参考；每个预警记录的关爱内容都单独保存

2. 归属与参考分开保存：`warningIds` 仅当前入口预警；`referenceWarningIds` 为其他参考线索。删除旧的多预警合并、记录搬移、原案替换、创建日期继承逻辑。无个案的参考预警不会自动创建个案；当前预警已有空个案时仅更新自身空个案。
3. 不同预警的记录、材料、版本、个案标识和创建日期独立。继续关爱只追加当前预警的原个案；学校和监管的计数与详情不读取参考关系。
4. 第一、二版“下次跟进日期”改为非必填，去除必填星号与空值阻断。仍在选择“需要”时显示；选择“不需要”仍隐藏并清空。只读卡片与详情保留字段位置，有值显示日期，无值显示“--”；已有列表中对应字段同口径，不额外新增列表列。
5. 关爱类型和方式枚举、班主任默认执行人员、锁定来源、既有基础权限与简单状态规则保持原样。字段顺序按最新确认统一为来源→关联信息→类型；下次日期提示仅“请选择日期”。第二版学校与四级监管列表为关爱次数（N次／--），详情补齐来源后的关联信息弹窗。暂不扩展多人、多次记录的个案状态变化场景；已同步第一期各端正式 PRD。

## 验证

- 老师端 DOM 回归：当前预警自动勾选、底部取消／确定、参考预警原个案及版本不被改写、参考无案不建案、新预警与继续关爱记录隔离、计数隔离、第一版重复建案规则；第一、二版需要跟进但不填日期可保存、详情显示“--”。
- 六端启动、内嵌脚本语法、相对资源引用及唯一 ID；学校和四级监管原字段、筛选、名称下钻、双 tab、菜单、删除权限与计数刷新。新增各 Web 端参考 ID 不影响次数的检查，以及空日期显示“--”／已填日期完整回显的检查。
- 复验命令：`node 控辍保学-关爱联动.test.cjs` 和 `node 控辍预警-Web联动.test.cjs`，在当前原型目录运行。

测试为本地 DOM 行为回归，不等于浏览器视觉、触摸手感或真实文件上传验收。原型仍为各页面独立演示数据，无跨端持久化。

V2.1 目录保留并标记已放弃，便于追溯，不删除原始资料，不将其新类型、多选措施或权限实验写回当前原型。
