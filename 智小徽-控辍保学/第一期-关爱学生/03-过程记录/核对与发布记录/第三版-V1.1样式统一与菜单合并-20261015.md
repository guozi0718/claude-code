# 第一期第三版 V1.1：样式统一与菜单合并

更新：2026-10-15。只调整第三版六端“关爱记录 / 关爱管理”的呈现与原型交互，业务流程、字段、校验和统计口径不变；第一版、第二版文件未改动。

## 改了什么

| 问题 | 处理 |
|---|---|
| 顶部状态栏丢失 | 老师端新增、编辑、详情页复制控辍保学页的状态栏、标题栏和小程序胶囊。 |
| 提示、校验按钮直接显示在页面上 | 删除“规则说明”“校验演示”按钮和演示身份下拉，统一收进顶部绿色小点。点开后浮窗分「场景」「异常」两类。老师端的小点在标题栏胶囊左侧；学校端在“查询”按钮左侧；监管端在标题行右侧；Web 详情弹窗在标题右侧。 |
| 选中值回显异常 | 不再使用原生下拉框和多行多选框，改为第一版底部选择器（单选圈 / 复选框，取消、确定并排）。确定后在字段行右侧单行回显；多选按字典顺序用顿号连接，超出宽度省略，悬停可看全文。 |
| 页面容器混乱 | Web 端隐藏左侧侧栏（原侧栏被缩放截断），关爱管理改为第一版全屏白卡片容器；老师端表单和详情使用第一版卡片、字段行与底部按钮。 |
| 设计风格不一致 | 统一沿用第一版关爱内容的配色、字号、卡片、表格、绿色查询按钮、详情弹窗和底部操作面板。 |
| 菜单没有合并 | Web 端所有功能菜单收进右上角蓝色功能菜单点：学校端依次为控辍劝返台账、控辍预警、预警配置、关爱管理、数据看板；监管端依次为控辍劝返台账、控辍预警、关爱管理、数据看板。切换后关闭关爱页面，当前菜单高亮。 |

## 按 PRD 补齐的原型交互

- 老师端：表单返回时弹出“放弃填写”确认；选择器无候选时显示“暂无可选{字段}”，并禁用确定；图片读取中显示“图片读取中…”，同时禁用确定；读取失败提示“图片读取失败，请重新选择”；版本冲突的提示改为 PRD 原文“记录已更新，请重新打开编辑 / 记录已更新，请重新打开”；学生失效时提示“学生信息已更新，请重新选择学生。”；搜索框显示候选；校验提示以红字显示在对应字段下方。
- Web 端：监管汇总页补上创建日期筛选，下钻时沿用当前日期，返回时恢复上一层的条件和页码；日期框支持手动输入，也可点日历选择；日期格式错误和日期范围错误分别提示 PRD 原文；学生姓名显示候选；详情弹窗可按 Esc 关闭；学校列表表头统一为“创建日期”。
- 文档里补充的细节都用绿色字标出（`<font color="green">`），三份 PRD 的文档版本升到 V1.2.0_261015。
